# OpenClaw with a local LLM: test images

Charts and screenshots from a test of OpenClaw 2026.11.1 with qwen3.5:9b in Ollama 0.30.10 on one RTX 3090 (8 November 2026).

- `images/prompt-tokens.png`: prompt tokens per model call, from the Ollama log
- `images/reply-times.png`: reply times, cold and warm
- `images/discord-mention-and-tool.png`: first Discord tests (question, then a file written with a tool)
- `images/discord-after-restart.png`: the model's reply after a restart
- `images/control-ui-chat.png`: listing the workspace in the web panel

Full setup guide: https://homebrewserver.club/openclaw-docker-ollama.html
